# Nyar
A Vulkan-based real-time renderer.

This project is designed as a separate module for the [Nodens](https://github.com/EldritchCodex/Nodens) framework. Its design and implementation draw from established principles in real-time rendering [^1] and modern engine architecture [^2][^4].

## Development

- **Immediate Goal:** Follow and complete the official Khronos Vulkan "Drawing a triangle" tutorial [^3] to establish a solid baseline.
- **Future Direction:** Incrementally refactor and morph the working tutorial code into a dedicated renderer API.
